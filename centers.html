    Preparing devices for disposal

    • Backup and factory reset devices if possible.
    • Remove SIM / memory cards and personal accessories.
    • Remove batteries if safe; otherwise, keep device intact and mark condition.

    By using this feature, you allow the website to access your device location for finding nearby e-waste centers. No location data is stored.
